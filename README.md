# 情感脑电信号处理与识别系统

本仓库是《人机交互选修课》大作业的实现代码，采用 **纯 Python 技术路线**。本项目通过 MNE-Python 库实现对脑电数据（如 DEAP/MAHNOB-HCI）的预处理、特征提取及情感分类任务，并包含了迁移学习/主动学习的对比实验。

## 任务完成情况

### 任务 1：脑电信号预处理 
- **数据导入**：支持 `.mat` 或 `.fif` 格式数据转换。
- **信号滤波**：带通滤波去除工频干扰。
- **伪迹去除**：利用 ICA（独立成分分析）去除眼电与肌电伪迹。
- **分段与校正**：以视频刺激为基准切分数据，并进行基线校正。

### 任务 2：情感计算基础建模
- **特征提取**：提取微分熵特征
- **分类器**：基于 `scikit-learn` 实现 SVM 、随机森林、多层感知器，进行效价二分类（消极/积极）和三分类（消极/中性/积极）

### 任务 3：跨被试迁移学习。 
  针对对脑电信号个体差异显著的问题，实现MLP-DANN、SVM-ASFM 和 RF-ASFM三种域自适应迁移学习方法，通过对比有迁移与无迁移的分类准确率，定量分析迁移学习对跨被试情感识别的改善效果。 

### 任务 4：结果分析与应用展望 
- 输出准确率、精确率、召回率及混淆矩阵。
- **应用设想**：基于脑电情感识别的自适应音乐推荐系统方案设计。
